# Bike Shop Invoices

A phone-sized web app for a bicycle repair shop to write invoices: customer, one or more bikes,
service notes, parts & labour lines, tax, and a printable preview. Invoices are saved in the
browser's localStorage.

```sh
npm install
npm run dev      # open the printed Network URL on your phone (same Wi-Fi)
npm run build    # type-check + production build into dist/
npm test         # vitest: calculations, storage, and UI flows
```
